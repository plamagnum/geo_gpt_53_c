# Проєкт: Веб-додаток для тестів з різних предметів

Цей проєкт є повноцінним web-додатком, що надає можливість учням проходити тести з різних предметів. Додаток підтримує функції реєстрації, авторизації, управління завданнями та підтримує як адресу середу php, так і API. Недалеко представлені парсери, що забезпечують гнучку обробку даних.

## Технології
- **Backend**: PHP
- **Frontend**: JavaScript
- **База даних**: MySQL
- **Управління**: phpMyAdmin
- **Контейнеризація**: Docker Compose
- **Сервер**: Nginx

## Кроки для налаштування
1. Встановіть Docker і Docker Compose.
2. Клонуйте репозиторій:
   ```
   git clone https://github.com/plamagnum/geo_gpt_53_c.git
   ```
3. Перейдіть до папки проекту:
   ```
   cd geo_gpt_53_c
   ```
4. Запустіть `docker-compose`:
   ```
   docker-compose up -d
   ```
5. Перейдіть до `http://localhost` для доступу до додатка.

## Реєстрація користувача
- Спрощена реєстрація учня з можливістю вибору ролі (user/admin).

## CRUD функціонал
Додаток підтримує функції CRUD для управління завданнями користувача з можливістю ручного додавання питань.

## Тестування
Тестування з 4 варіантами відповіді, з підсвіткою правильних і неправильних відповідей.

## Документація
Для отримання додаткової інформації про використання API, будь ласка, ознайомтеся з документацією в `api`.

## Адаптивний дизайн
Додаток підтримує адаптивний mobile-first дизайн.

## Парсери
Додаткові парсери для обробки даних:** PHP та Python**, з можливістю редагування лише HTML тегів/селекторів.
